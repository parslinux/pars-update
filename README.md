# Pars Update (pars-update)

**Pars Update**, Pars Linux, Arch Linux ve Debian tabanlı işletim sistemleri için geliştirilmiş, çoklu paket yöneticisi (Pacman & APT) destekli, hafif, güvenli ve modern bir grafiksel güncelleme yöneticisidir.

Detaylı dokümantasyon, ekran görüntüleri ve mimari şemalar için [docs/README.md](docs/README.md) ve [docs/](docs/) dizinini inceleyebilirsiniz.

---

## 🚀 Hızlı Başlangıç

```bash
# Modern Libadwaita / GTK4 arayüzü ile başlat:
./pars-update

# Arka planda kontrol et:
./pars-update --check

# Klasik GTK3 arayüzü ile başlat:
./pars-update --gtk3

# Testleri çalıştır:
python3 -m unittest discover tests
```

Tüm kılavuzlar ve modül detayları: [docs/README.md](docs/README.md)
